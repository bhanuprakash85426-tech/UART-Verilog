# UART-Verilog
Verilog-based UART Transmitter and Receiver with FSM design, testbenches, and waveform verification.
# UART Verilog Design

## Overview
A UART (Universal Asynchronous Receiver/Transmitter) designed using Verilog HDL.

## Features
- UART Transmitter (TX)
- UART Receiver (RX)
- FSM-based design
- Start bit
- 8-bit data transmission
- Stop bit
- Testbenches for TX and RX
- Waveform verification

## Tools Used
- Verilog HDL
- EDA Playground
- Waveform Viewer

## Verification
Both TX and RX were simulated and verified using testbenches and waveform analysis.
